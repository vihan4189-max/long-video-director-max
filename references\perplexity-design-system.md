# Perplexity Editorial Design System & Brand Specification

This document defines the strict visual identity, typography hierarchy, color codes, border treatments, citation conventions, and motion curves matching **Perplexity ([www.perplexity.ai](https://www.perplexity.ai))**. Every frame, motion graphic, card, and subtitle generated by Hyperframes and Clipchat must strictly adhere to these design tokens.

---

## 1. Color Palette Tokens

The Perplexity aesthetic relies on deep matte slate canvases, crisp hairline borders, high-contrast readable typography, and electric cyan accents.

### Dark Theme (Primary Video Canvas)
```css
:root {
  /* Canvas Backgrounds */
  --pplx-canvas-bg: #111418;          /* Primary matte background */
  --pplx-surface-card: #16191E;        /* Standard elevated card container */
  --pplx-surface-subtle: #1D222A;      /* Interactive hover / secondary card */
  --pplx-surface-input: #1B1F26;       /* Query search box input fill */

  /* Hairline Borders */
  --pplx-border-subtle: #23272F;       /* Standard 1px card boundary */
  --pplx-border-focused: #2F3642;      /* Focused card or active pill border */
  --pplx-border-accent: #20B8CD44;     /* Cyan glowing highlight border (25% alpha) */

  /* Text & Typography */
  --pplx-text-primary: #F3F3EE;        /* Perplexity signature off-white warm text */
  --pplx-text-secondary: #9DA3AE;      /* Editorial metadata, timestamps, author lines */
  --pplx-text-muted: #646C7A;          /* Footnotes, inactive labels, watermark text */

  /* Brand Accents */
  --pplx-accent-cyan: #20B8CD;         /* Main Perplexity teal/cyan */
  --pplx-accent-cyan-glow: #20B8CD22;  /* Subtle cyan halo/badge background */
  --pplx-accent-deep-cyan: #00A3BF;    /* Gradient terminal or pressed state */
  --pplx-accent-amber: #E5A93C;        /* Alert, myth-busting, benchmark anomaly */
  --pplx-accent-crimson: #EF4444;      /* Error, debunked claims, fatal bugs */
  --pplx-accent-emerald: #10B981;      /* Verified accuracy, performance speedup */
}
```

### Academic Light Theme (Paper Abstract & Math Parchment Inserts)

## 3. Card Containers & Spatial Architecture

Perplexity’s UI is defined by floating rounded cards with crisp hairline borders:
- **Card Corner Radius**:
  - Main display cards: `16px` border-radius.
  - Small pills & citation tags: `9999px` full pill radius.
  - Search input box: `24px` border-radius.
- **Card Border**: Exactly `1px solid #23272F` (never 2px, never blurred borders).
- **Subtle Elevation Shadow**:
  `box-shadow: 0 4px 20px -2px rgba(0, 0, 0, 0.5), 0 2px 6px -1px rgba(0, 0, 0, 0.3);`
- **Inner Padding**:
  - Cards: `28px` to `36px` on 1080px canvas width.
  - Citation pills: `6px 14px`.

## 4. Perplexity Citation Badge System

One of Perplexity’s most iconic visual signatures is the citation badge:
- **Badge Anatomy**:
  - Small circular or rounded favicon / paper icon (16x16px).
  - Source domain text (e.g. `arxiv.org`, `nature.com`, `github.com`).
  - Index marker in brackets: `[1]`, `[2]`, `[3]`.

## 5. Motion Curves & Spring Physics

Amateur video editing uses linear keyframes or exaggerated bouncing. Perplexity motion is weighted, physical, smooth, and rapid on entrance:

### The Canonical Motion Curves
1. **Perplexity Signature Spring (Fast In, Smooth Decel)**:
   `cubic-bezier(0.16, 1, 0.3, 1)`
   *Use for: Card reveals, drawer slides, query bar expansions, chart draw-in.*
2. **Snappy Micro-Interaction (Pills, Citations)**:
   `cubic-bezier(0.2, 0.8, 0.2, 1)`
   *Duration: 220ms – 300ms.*
3. **Smooth Exit / Dissolve**:
   `cubic-bezier(0.4, 0, 1, 1)`
   *Duration: 180ms – 240ms.*

### Vertical Motion Rule
Items never fly in from crazy 3D angles.
- Enter with an initial `+12px` Y-translation rising to `0px` simultaneously with opacity from `0%` to `100%`.
- Stagger multi-item lists by exactly `60ms` per item.

## 6. Kinetic Subtitles Specification

Subtitles for no-face videos must be effortless to read and never obstruct visual content:
- **Position**: Bottom-center safe zone (`Y = 1480px` to `Y = 1620px` in 1080x1920).
- **Format**: 3 to 5 words max displayed at any instant.
- **Active Word Treatment**:
  - Inactive words: `#9DA3AE` (muted slate, 80% opacity).
  - Active spoken word: `#F3F3EE` (Perplexity warm white) with a subtle glowing cyan underline or cyan background pill highlight (`rgba(32, 184, 205, 0.2)`).
- **Font**: Inter Bold, 44px, uppercase or title case, zero emojis.
